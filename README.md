# Breast Cancer Prediction System

## Project Description
This project predicts whether a breast tumor is Benign or Malignant using a Random Forest Classifier.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Streamlit
- Matplotlib

## Machine Learning Algorithm
Random Forest Classifier

## Features Used
- Radius Mean
- Texture Mean
- Perimeter Mean
- Area Mean
- Concave Points Mean
- Radius Worst
- Area Worst

## Run the Project

Train Model

python main.py

Run Streamlit App

streamlit run app.py
